# Hi, I'm Carlos

I build infrastructure for reliable AI agents, with a focus on execution coordination, memory governance, and runtime systems.

I'm interested in how these systems behave over time: who owns a task, what happens when a worker fails, and how an agent's memory can be traced, corrected, and replayed.

## Selected Work

### RaftKV

Strongly consistent execution coordination for self-hosted agents and workers. It provides fenced task ownership, safe takeover, and single-winner result publication.

### sptem-graph

A local-first memory governance engine for AI agents. It tracks time-scoped claims and their evidence so developers can explain, replay, and selectively retire agent memories.

### Zephyr

A C++20 coroutine runtime project for Linux, focused on asynchronous execution and runtime foundations.

## Interests

Beyond these projects, I explore AI runtime and serving systems, GPU performance, graph intelligence, world models, and reinforcement learning.

I also build local tools that connect research, knowledge management, and day-to-day engineering.

## How I Work

- Build in small, verifiable steps with clear contracts and explicit failure behavior.
- Keep architecture grounded in code, tests, and reproducible checks.
- Use AI tools as engineering collaborators, and verify their output against implementation evidence.
